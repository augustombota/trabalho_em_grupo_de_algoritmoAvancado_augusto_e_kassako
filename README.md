# Simulador do Algoritmo de Bellman-Ford (JavaFX)

Repositório oficial do projeto prático / Trabalho de Algoitmo de Bellman Ford desenvolvido no âmbito da cadeira de Algoritmos Avançados na **Universidade Kimpa Vita** (Instituto Politécnico do Uíge).

##  Sobre o Projeto
Esta aplicação desktop foi desenvolvida em **Java 17** utilizando **JavaFX** e **Maven**. O objetivo principal é fornecer uma ferramenta visual e interativa para simular o funcionamento do **Algoritmo de Bellman-Ford** em grafos direcionados, permitindo calcular distâncias mínimas a partir de um vértice de origem e detetar automaticamente ciclos de custo negativo.

## Funcionalidades Principais
* **Visualização Gráfica do Grafo:** Representação vetorial interativa dos nós (vértices) e arestas direcionadas com os respetivos pesos.
* **Tabela de Resultados Dinâmica:** Apresentação em tempo real das distâncias mínimas e predecessores calculados.
* **Consola de Logs Detalhada:** Registo passo a passo de todas as iterações de relaxamento das arestas.
* **Deteção de Ciclos Negativos:** Alerta visual e lógico imediato caso o grafo contenha ciclos de custo negativo.

## Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Java 17
* **Interface Gráfica:** JavaFX (FXML)
* **Gestor de Dependências / Build:** Apache Maven / Maven Wrapper
* **Ambiente de Desenvolvimento:** IntelliJ IDEA
